# Файлы конфигурации

Все файлы лежат в папке `Файлы конфигурации` рядом с исполняемым файлом.
Папка создаётся автоматически при первом запуске; недостающие файлы
заполняются значениями по умолчанию.

Заменить любой файл своим можно через раздел **Настройки → Файлы
конфигураций**. Выбранный путь сохраняется в `settings.json`, а если файл
не выбран или не найден — используется файл по умолчанию из папки
конфигурации. Кнопка «Вернуть файлы по умолчанию» сбрасывает все пути.

---

## Текстовые файлы

К этому типу относятся:

- `Значащие слова.txt`
- `Удаляемые_окончания.txt`
- `Слова удаления кода.txt`

### Формат

```
<заголовок>
<строка с правилами добавления>
<пустая строка>
<значение 1>
<значение 2>
...
```

Первые три строки служебные. Значения читаются **начиная с четвёртой
строки**. Пустые строки внутри списка пропускаются.

Пример — `Слова удаления кода.txt`:

```
Слова, при наличии которых в начале коммерческого кода он полностью удаляется
Правила добавления слов: по одному значению в строке, без пробелов в начале и в конце

конденсатор
болт
винт
шайба
гайка
саморез
шуруп
хомут
```

### Кодировка

Файлы читаются как UTF-8. Если в файле есть признаки другой кодировки,
применяется Windows-1251 — поддержка подключена через
`System.Text.Encoding.CodePages`.

## Артикулы_исключения.xlsx

Определяет, для каких артикулов коммерческий код не нужен. Файл содержит
три листа, и на каждом своя логика сопоставления.

| Лист | Условие срабатывания |
|---|---|
| `Начинается с` | артикул начинается с указанного текста |
| `Заканчивается на` | артикул заканчивается указанным текстом |
| `Содержит` | артикул содержит указанный текст |

### Формат листа

Первая строка — заголовок, данные читаются со второй строки. Значения
берутся из **первой колонки**.

| A |
|---|
| Начало артикула, для которого коммерческий код не нужен |
| SRF50 |
| SUA70-55 |

### Маска `*`

В значениях допустим символ `*` — он означает **ровно один** любой
символ, а не произвольное количество.

| Значение | Совпадёт | Не совпадёт |
|---|---|---|
| `DN**` | `DN15`, `DN50` | `DN5`, `DN150` |
| `-***9-` | `-1239-` | `-129-`, `-12349-` |

Если лист с ожидаемым названием не найден, в отчёте о загрузке появится
предупреждение, а правила этого листа не применятся.

## Замены символов.xlsx

Карта замен для правила «Замена кирилл. А на англ. A и подобных».
Две колонки: что заменяем и на что.

| A | B |
|---|---|
| Заменяемый символ | Корректный символ |
| А | A |
| В | B |
| Е | E |
| К | K |
| М | M |

Первая строка — заголовок, данные читаются со второй строки. В первой
колонке должен быть **ровно один символ** — иначе строка пропускается
с предупреждением.

### Защита от ложных замен

Замена применяется к значению целиком **только при отсутствии в нём
кириллицы вне карты**. Например, для значения `ПЗК-RU52` буква `П` не
входит в карту — значение остаётся без изменений.

Отдельно защищаются марки стали на кириллице (`08Х18Н10`, `12Х18Н10Т`,
`40ХН2МА`) и найденные в настройках «неизменяемые сочетания кириллицы».

## Правила проверки комм. кода для ИМ.xlsx

Набор правил для проверки кодов интернет-магазина. Каждое правило
задаёт тип сопоставления и образец.

| Тип | Условие |
|---|---|
| `Начинается с` | код начинается с образца |
| `Заканчивается на` | код заканчивается образцом |
| `Содержит` | код содержит образец |

Маска `*` работает так же, как в файле исключений — ровно один символ.

## Правила проверки артикула для ИМ.xlsx

То же самое, но проверяется не код, а артикул. Позволяет отсеивать
позиции, которые не должны попадать в выгрузку для интернет-магазина,
независимо от вида коммерческого кода.

---

## правила обработки значений коммерческого кода.txt

Текст справки, который показывается в разделе «Настройки → Правила
проверки комм. кодов». Содержимое выводится как есть. Если файл
отсутствует, используется встроенный текст `RuleCatalog.FallbackRulesText`.

## Настройки приложения

`settings.json` лежит рядом с исполняемым файлом и создаётся
автоматически. В нём хранятся:

| Ключ | Назначение |
|---|---|
| `EnabledRules` | включённые правила |
| `WordsFilePath` | путь к файлу значащих слов |
| `EndingsFilePath` | путь к файлу окончаний |
| `ExclusionsFilePath` | путь к файлу исключений |
| `ForceDeleteWordsFilePath` | путь к файлу слов удаления кода |
| `CharMapFilePath` | путь к карте замен |
| `ImRulesFilePath` | правила проверки кода для ИМ |
| `ImArticleRulesFilePath` | правила проверки артикула для ИМ |
| `Morphology` | режим словоформ |
| `Extra1CChars` | дополнительные символы, допустимые в коде для 1С |
| `CyrillicExceptions` | сочетания кириллицы, не подлежащие замене |
| `CodeFontPx`, `RulesFontPx`, `SummaryFontPx`, `ButtonFontPx`, `TabTextFontPx` | размеры шрифтов интерфейса |

Если файл повреждён, приложение молча берёт значения по умолчанию.

### Режимы словоформ

`Morphology` влияет на то, как раскрываются слова из файла значащих слов.

| Значение | Поведение |
|---|---|
| `Off` | словоформы не раскрываются, сравнение по точной форме |
| `Paradigms` | раскрытие по парадигмам, умеренная агрессивность |
| `Aggressive` | более широкое раскрытие за счёт точности |

## Справочный файл Help.rtf

Окно справки читает `Ресурсы/Help.rtf` рядом с исполняемым файлом.
Файл кладётся вручную при публикации. Если его нет, окно справки
покажет сообщение об отсутствии файла.
